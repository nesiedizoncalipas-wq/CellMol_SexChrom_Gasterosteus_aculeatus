## 6. R Analysis

The analysis uses base R to calculate relative chromosome depth.

**Input files:**
- `chromosome_coverage.tsv`
- `chromosome_groups.csv`

**R script:** `scripts/sex_depth_analysis.R`

The analysis will calculate:

- Median autosomal read depth
- Relative chromosome depth
- X-to-autosome (X:A) depth ratio
- Optional Y-to-autosome (Y:A) depth ratio

The classroom interpretation guidelines are:

| X:A ratio | Interpretation |
|---|---|
| ≥ 0.80 | XX-like |
| ≤ 0.65 | XY-like |
| Between 0.65 and 0.80 | Ambiguous |

An autosomal median depth below 1 indicates an inconclusive result.

### 6. Why is a chromosome-level assembly alone insufficient for a reliable read-depth sex inference?

A chromosome-level assembly identifies chromosome sequences and their organization, but it does not provide the read-depth evidence needed to estimate the sex-chromosome complement of an individual. Whole-genome sequencing reads must be mapped to the reference genome, and the resulting chromosome coverage must be compared with autosomal coverage.

## 9. Limitations

Read-depth analysis may be affected by:

- Low sequencing depth
- Mapping bias
- Repetitive sequences
- Pseudoautosomal regions
- Poorly differentiated sex chromosomes
- Missing Y-chromosome sequences
- Reference genome errors
- Unusual chromosome complements

A near-zero Y-chromosome depth alone does not prove that the Y chromosome is absent. The interpretation must consider the overall coverage pattern and available sample metadata.
